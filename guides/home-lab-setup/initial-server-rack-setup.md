# Initial Server Rack Setup

> Manual: Home Lab Setup  
> Last updated: 2026-04-01T22:34:30.055Z
## Overview

This guide covers the physical setup of the primary server rack in the home lab.

## Hardware Checklist

- [ ] 12U open-frame rack secured to floor/wall
- [ ] 1U patch panel (24-port Cat6)
- [ ] 2U UPS (CyberPower 1500VA)
- [ ] Cable management rings

## Steps

1. Assemble rack frame per manufacturer instructions.
2. Mount UPS at the bottom for low center of gravity.
3. Install patch panel at 1U.
4. Mount servers from bottom up.
5. Label all patch panel ports with a labelmaker.

## Notes

Leave at least 1U of empty space between heat-producing devices.
